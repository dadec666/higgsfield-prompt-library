## 📊 ТАБЛИЦА: СООТВЕТСТВИЕ MOTION → АСПЕКТ-РЕЙШО

| Motion | Лучший Aspect Ratio | Причина |
|--------|-------------------|---------|
| **FPV Drone** | 16:9 | Широкий формат подходит для полета |
| **360 Orbit** | 16:9 или 1:1 | Круговое движение требует симметрии |
| **Dolly Controls** | 16:9 или 4:5 | Универсальны для большинства |
| **Crane Up/Down** | 16:9 | Вертикальное движение в широком формате |
| **Snorricam** | 16:9 (Закадровая) | Фокус на лице, тело может быть обрезано |
| **Overhead** | 1:1 или 4:5 | Сверху вниз требует квадратного формата |
| **Handheld** | 9:16 (для TikTok) | Интимно, вертикально, документально |
| **Whip Pan** | 16:9 | Горизонтальное движение |

## ⚡ БЫСТРЫЕ СОВЕТЫ ДЛЯ ЛУЧШИХ РЕЗУЛЬТАТОВ

### СДЕЛАЙ ✅

1. **Будь специфичен**
   ```
   ❌ "cool drone shot"
   ✅ "FPV drone diving through futuristic city neon streets at night"
   ```

2. **Комбинируй 2-3 motion controls максимум**
   ```
   ✅ "Dolly In + Focus Change"
   ❌ "Dolly In + Orbit + Crane + Zoom + Pan" (слишком много)
   ```

3. **Specify lighting явно**
   ```
   ✅ "warm sunset golden light casting long shadows"
   ❌ "nice lighting"
   ```

4. **Используй кинематографический язык**
   ```
   ✅ "low angle Dutch tilt"
   ❌ "tilted camera"
   ```

5. **Заканчивай описанием эмоционального тона**
   ```
   ✅ "blending fear and determination into single exhilarating moment"
   ❌ "dramatic"
   ```

### НЕ ДЕЛАЙ ❌

1. **Не используй conflicting motions**
   ```
   ❌ "Handheld + Robo Arm" (противоречат)
   ✅ "Steady Robo Arm" ИЛИ "Organic Handheld"
   ```

2. **Не пиши слишком абстрактно**
   ```
   ❌ "beautiful cinematic video with good energy"
   ✅ "cinematic with warm color grading and steady dolly movement"
   ```

3. **Не забывай про длительность**
   ```
   ❌ Промпт на 10 секунд для 3-5 второго видео
   ✅ Компактный промпт с одним ключевым движением
   ```

4. **Не переполняй слишком много деталей**
   ```
   ❌ Огромный стена текста на 100+ слов
   ✅ Фокусированный 50-75 слов промпт на ключевые элементы
   ```

5. **Не игнорируй аспект-рейшо**
   ```
   ❌ Генерируешь в 16:9 для вертикального контента
   ✅ Выбираешь 9:16 или 4:5 для TikTok/Reels
   ```

## 🎯 РАСПРОСТРАНЕННЫЕ ОШИБКИ И КАК ИХ ИЗБЕЖАТЬ

### Ошибка 1: Слишком сложный промпт
```
❌ НЕПРАВИЛЬНО:
"Create a dynamic cinematic sequence where the protagonist, a weathered warrior 
with battle scars and torn armor, stands majestically on a desolate mountain peak 
overlooking a vast kingdom below as the sun sets with golden rays filtering through 
ancient trees while a mysterious storm approaches in the distance and the camera 
performs a complex series of movements including orbiting, craning, dollying, and 
zooming simultaneously while maintaining focus on the character's determined expression..."

✅ ПРАВИЛЬНО:
"A weathered warrior stands on mountain peak overlooking vast kingdom. Sunset casts 
golden light. The camera cranes up from ground to reveal expansive landscape below, 
emphasizing his isolation and power. Storm clouds approach ominously in distance."
```

### Ошибка 2: Conflicting motions
```
❌ НЕПРАВИЛЬНО:
"Handheld camera orbits smoothly 360 degrees" (contradictory)

✅ ПРАВИЛЬНО:
"Steady camera orbits smoothly 360 degrees" ИЛИ 
"Handheld camera follows character erratically"
```

### Ошибка 3: Неправильный аспект-рейшо для платформы
```
❌ НЕПРАВИЛЬНО:
"Create a 16:9 landscape video for TikTok"

✅ ПРАВИЛЬНО:
"Create a 9:16 vertical video for TikTok"
```

### Ошибка 4: Забывание про стиль и настроение
```
❌ НЕПРАВИЛЬНО:
"A person dancing to music"

✅ ПРАВИЛЬНО:
"A confident person dancing energetically in neon-lit club. High-energy, urban style, 
exciting mood. Camera snap-cuts forward with beat."
```

### Ошибка 5: Генерирование 30-сек промпта для 3-сек видео
```
❌ НЕПРАВИЛЬНО:
"Over 30 seconds, we see the character walk from building A to building B, 
enter the building, climb stairs, open door, see the treasure..."

✅ ПРАВИЛЬНО:
"Character approaches building door with determination. Camera dolly in as door 
opens. 3-5 second sequence."
```
